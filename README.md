# Halde — Modern Furniture Studio

Website brand furnitur modern (kursi, meja, lampu & objek interior) dengan tipografi Inter, kanvas putih, dan animasi smooth berbasis GSAP + ScrollTrigger + Lenis.

🔗 **Live website (24/7):** https://aldnzrr.github.io/Project-19/

## Jalankan lokal

```bash
node server.js
# buka http://localhost:5173
```

## Stack
- HTML / CSS / JavaScript statis (tanpa build step)
- GSAP 3 + ScrollTrigger
- Lenis smooth scroll
- Foto: Unsplash
